# P1 Index (User)

P1은 사용자 계정과 사용자가 소유하는 기본 리소스를 정의한다. 사용자 계정의 인증 수단과 토큰 처리는 P11 Auth가 담당하고, P1은 인증된 사용자의 프로필·권한·주소를 관리한다.

## 1. 범위

- 사용자 계정 상태와 역할
- 본인 프로필 조회·수정
- 사용자 소유 주소의 등록·조회·수정·삭제
- 관리자에 의한 사용자 리소스 관리

## 2. 문서 구성

- [P1 User](p1-user.md): 사용자 모델, API, 권한, 주소와 예외

## 3. 도메인 경계

| 도메인 | P1과의 관계 |
|---|---|
| P11 Auth | 회원가입·로그인·토큰·OAuth 인증 수단 관리 |
| P5 Order | 주문 화면에서 사용자의 배송지 조회 |
| P7 Admin | 관리자용 사용자 운영 기능 |

공통 응답 형식과 HTTP 예외 규칙은 [공통 API 계약](../index.md#공통-api-계약)을 따른다.
