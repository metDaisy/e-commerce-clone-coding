# P3 Index (Cart)

P3는 사용자가 구매할 상품을 임시로 보관하는 장바구니를 정의한다. 장바구니와 장바구니 항목은 사용자별로 관리하며, 주문 생성 시 선택된 항목을 P5 Order로 전달한다.

## 1. 범위

- 회원·비회원 장바구니
- 상품 항목 추가·수량 변경·삭제
- 장바구니 조회와 항목 소유권 검증
- 결제 완료 후 장바구니 항목 정리

## 2. 문서 구성

- [P3 Cart](p3-cart.md): API, `carts`·`cart_items` 데이터 모델, 기본 규칙과 예외

## 3. 처리 흐름

```text
상품 선택 → 장바구니 추가·수량 변경
        → 장바구니 조회 및 선택
        → P5 Order에 cart item ids 전달
        → 결제 완료 후 주문 항목 정리
```

장바구니 검증과 가격·재고·쿠폰·포인트 계산은 주문 생성 시 P5가 최종 수행한다. P3는 주문과 결제 상태를 소유하지 않는다.

공통 응답 형식과 HTTP 예외 규칙은 [공통 API 계약](../index.md#공통-api-계약)을 따른다.
