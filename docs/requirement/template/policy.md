## 5. 도메인 간 규칙과 예외 소유권

- 다른 도메인의 리소스를 조회하거나 자격을 확인할 때는 해당 도메인의 공개 계약을 사용한다.
- 다른 도메인에서 발생한 예외는 이 도메인의 API 응답 목록에 포함하되, `exceptionCode`, client message, system message의 원본은 해당 도메인 문서를 참조한다.
- 외부 예외 표에는 소유 도메인의 코드를 링크로 남기고, 발생 조건·client message·details·system message는 `—`로 둔다. 원본의 의미와 메시지를 다시 작성하지 않는다.
- 이 도메인이 외부 예외를 사용자용 예외로 변환한다면 변환 코드와 이유를 명시한다.

| 외부 도메인 | 사용 목적 | 공개 계약·정책 참조 |
|---|---|---|
| [P? 외부 도메인] | [조회·자격·상태 확인] | [문서 링크] |

## 6. API 문서와의 관계

- API별 요청·성공 응답·예외 매트릭스는 [[리소스] API]([resource].md)에서 정의한다.
- 이 문서의 정책과 API 문서의 요구사항이 충돌하면 이 문서의 정책을 기준으로 API 문서를 수정한다.
- 공통 오류 응답 필드는 [공통 API 계약](../index.md#공통-api-계약)을 따르고, 도메인별 `exceptionCode`는 API 문서에 등록한다.
