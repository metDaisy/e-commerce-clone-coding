[도메인]의 요구사항 문서 목록과 책임 경계를 안내한다. 정책과 API의 상세 내용은 아래 연결된 문서에서 정의한다.

## 1. 문서 목록

| 문서 | 역할 | 포함 내용 |
|---|---|---|
| [P? Policy](p?-policy.md) | 정책 | 범위·책임, 행위자, 업무 규칙, 불변식, 상태 전이, 도메인 간 규칙 |
| [[리소스] API]([resource].md) | 데이터 모델·API | 데이터 모델, 관계·제약, API 요청·성공 응답·예외 매트릭스 |

리소스의 행위자·상태·심사 흐름이 서로 다르고 문서가 길어지면 `[resource]-[concern].md`를 추가한다. 추가 문서는 반드시 이 인덱스에 등록하고, 기존 문서에서 담당 범위를 참조한다.

## 2. 책임과 경계

| 책임 | 담당 도메인·모듈 | 참조 문서 |
|---|---|---|
| [핵심 리소스] 원본·상태·공개 여부 | [P? 도메인] | [[리소스] API]([resource].md) |
| 구매·소유·인증 자격 확인 | [P? 외부 도메인] | [외부 문서 링크] |
| 파일·결제·배송 등 공통 기능 | [P? 외부 도메인] | [외부 문서 링크] |

- 이 도메인이 소유하는 데이터와 정책을 명시한다.
- 다른 도메인의 내부 모델·Repository·서비스 구현은 소유하지 않는다.
- 다른 도메인의 예외는 이 도메인의 API 응답 목록에 포함할 수 있지만, 예외 코드·메시지의 원본 정의는 리소스 소유 도메인을 참조한다.
- 공통 URI, 성공 응답 원칙, 예외 응답 필드, 페이지네이션, 인증은 [공통 API 계약](../index.md#공통-api-계약)을 따른다.

## 3. 문서 작성 순서

1. [P? Policy](p?-policy.md)에서 범위·책임과 확정 업무 규칙을 정한다.
2. [[리소스] API]([resource].md)에서 정책을 만족하는 데이터 모델과 API를 정의한다.
3. API별 가능한 성공·예외 응답과 외부 도메인 예외 참조를 완성한다.
4. 이 문서의 문서 목록과 책임 표를 갱신한다.

## 4. 작성 원칙

- 이 문서는 안내와 책임 경계만 작성하고, 정책·필드·API 계약을 중복해서 작성하지 않는다.
- 구현 결과가 달라질 수 있는 선택 표현 대신 하나의 기본 동작을 확정한다.
- 문서 간 규칙이 충돌하면 소유 도메인의 정책 문서를 우선하고, 인덱스의 책임 표를 갱신한다.
