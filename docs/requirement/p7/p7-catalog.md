# P7 Catalog Administration (Catalog 관리·심사)

P2 Catalog가 Category·CatalogProduct·ProductVariant의 정식 데이터와 검증을 소유하며, P7은 관리자용 HTTP 진입점과 심사 처리를 제공한다.

## 문서 구성

| 문서 | 범위 |
|---|---|
| [P7 Category Administration](p7-category.md) | Category 생성·수정 |
| [P7 CatalogProduct Administration](p7-catalog-products.md) | CatalogProduct·ProductVariant 관리자 목록 |
| [P7 Catalog Registration Review](p7-catalog-requests.md) | 판매자의 Category·CatalogProduct·ProductVariant 등록 요청 목록·승인·거절 |

공통 응답 봉투와 예외 규칙은 [공통 API 계약](../index.md#공통-api-계약)을 따른다. P7 전체 API 목록은 [P7 Admin](p7-admin.md)을 참조한다.
